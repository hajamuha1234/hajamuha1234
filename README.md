## 👨‍💻 About Me

I'm **Muhammed Haja**, a cybersecurity learner from Kerala, India, with a background in computer applications and a strong interest in building a career in **Security Operations Center (SOC) operations and cybersecurity analysis**.

I enjoy learning how networks communicate, how web applications can be vulnerable, how security tools identify weaknesses, and how defenders can detect and investigate suspicious activities.

I'm currently pursuing **Offenso Certified Security Professional (OCSP) training at Offenso Hackers Academy, Kochi**, while developing my practical knowledge of cybersecurity tools, Linux, networking, web security, and vulnerability assessment.

My goal is to start my professional cybersecurity career in a role where I can contribute to security monitoring, threat detection, log analysis, incident investigation, and continuous improvement of defensive security practices.

### 🎯 Career Objective

To begin my career as a **SOC Analyst / Security Analyst**, apply my foundational cybersecurity knowledge in practical environments, strengthen my analytical and troubleshooting skills, and grow into a security professional capable of identifying, investigating, and responding to cyber threats.
